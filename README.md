<h1 align="center">WhaTicket by Gigabaite Tecnologia</h1> 
<h2 align="center">Sistema de tickets completo baseado em mensagens do WhatsApp com multiatendimento e integração com Chat GPT</h2> 

## Instruções de Instalação

Primeira instalação:

```bash
sudo apt install -y git && git clone https://github.com/oanselmogomes/stp install && sudo chmod -R 777 ./install && cd ./install && sudo ./install_primaria
```

Instalação de instância:

```bash
cd && cd ./install && sudo ./install_instancia
```

## Requisitos do Sistema

- VPS Ubuntu 20.04 com 3 vCPU's + 4 GB RAM)
- Subdominio para Frontend
- Subdominio para API
- E-mail válido para certificação SSL
